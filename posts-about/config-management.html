xDebug config in VS Code for lando

To add xdebug config to VS CODE for lando, use this config

{
    "version": "0.2.0",
    "configurations": [
      {
        "name": "Listen for XDebug",
        "type": "php",
        "request": "launch",
        "port": 9000,
        "pathMappings": {
          "/app/": "${workspaceFolder}/",
        }
      }
    ]
  }
